韌體版本 正在讀取

安裝會覆蓋現有韌體並清除裝置設定。請先記下 Wi-Fi 和小工具設定。

安裝前確認

  • 使用可傳輸資料的 USB 線，而非只供充電的線材。
  • 關閉其他正在使用序列連接埠的程式。
  • 確認裝置型號與上方選擇完全相同。

如未能找到連接埠，按住 BOOT 鍵再重新接上 USB。

基本操作

整個安裝在瀏覽器內完成，一般只需數分鐘。

  1. 1

    連接裝置

    使用 USB 數據線連接電腦，並保持裝置供電穩定。

  2. 2

    授權連接埠

    按「連接裝置並安裝」，在瀏覽器視窗選擇新增的 USB 連接埠。

  3. 3

    完成寫入

    不要拔除線材或關閉分頁。完成後裝置會重新啟動。

首次啟動設定

裝置首次啟動時會建立設定用 Wi-Fi。手機或電腦不需要安裝額外應用程式。

Wi-Fi 名稱 TransitInk-xxxx
設定網址 http://192.168.4.1/

在設定頁完成以下項目

  • 連接網絡 輸入日常使用的 Wi-Fi 名稱及密碼。
  • 安排主畫面 選擇四個小工具、排列次序，或停用不需要的位置。
  • 設定更新 選擇更新頻率、省電模式和交通路線資料。

疑難排解

遇到問題時，可保留現有頁面並逐項檢查。

找不到裝置或連接埠

更換可傳輸資料的 USB 線或連接埠，然後按住 BOOT 鍵重新連接。

安裝途中中斷

重新接上裝置並再次開始安裝。完成前不要關閉分頁或拔除線材。

安裝後沒有顯示設定網絡

重新啟動裝置並等待片刻，再於 Wi-Fi 清單尋找 TransitInk-xxxx。

我的裝置不在清單內

請勿嘗試使用其他型號的韌體。開發者可參閱 新增硬件指南。
